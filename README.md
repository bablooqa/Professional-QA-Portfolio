## 🏃‍♂️ Running Locally

1. **Clone the repo**
   ```bash
   git clone https://github.com/bablooqa/Professional-QA-Portfolio.git
   cd Professional-QA-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```
